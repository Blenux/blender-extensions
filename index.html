How to Add This Repository

Add this extension repository to Blender using either of the methods below.

1

Add Repository URL

  1. Open Edit → Preferences → Extensions
  2. Click the + button to add a new repository
  3. Paste the URL below into Repository URL
  4. Click Confirm — extensions will appear in the list
2

Drag & Drop Extension

Drag and drop an extension's .zip link from the table above directly onto the Blender window. This will add the repository so the extension is available to install.
